# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
v2.1. In short: be respectful, assume good faith, and keep disagreements
about code and design, not people.

Report unacceptable behavior by opening an issue, or, for anything
sensitive, via GitHub's private security advisory process described in
[SECURITY.md](SECURITY.md) (`Security` tab → `Report a vulnerability`
also reaches the maintainer privately for non-technical reports). As a
solo-maintained project there is no formal enforcement committee;
reports will be handled directly by the maintainer.
